# 机械臂视觉与吸盘接线总结

## 1. 系统角色分工

| 模块 | 主要职责 | 备注 |
| --- | --- | --- |
| STM32F407 | 发送开始抓取、停止抓取、查询状态等高级指令 | 不直接处理 MaixCAM2 图像坐标 |
| ESP32 机械臂控制板 | 接收 F4 指令、读取 MaixCAM2 视觉结果、控制机械臂和吸盘 | 抓取闭环放在 ESP32 侧实现 |
| MaixCAM2 | 安装在机械臂末端，识别金属零件并输出目标偏差 | 建议输出 `found/dx/dy/angle/score/area/frame_id` |
| 总线舵机机械臂 | 执行移动、对准、下降、抬起、放置动作 | 继续使用控制板的总线舵机接口 |
| 真空吸盘套件 | 替代夹爪完成吸取和释放 | 推荐使用带 2 个 PWM 电子开关的版本 |

## 2. 已确认的控制板接口

资料来源：`D:\机械臂\SCH_3in1 Servo Controller V3.1.pdf` 和 ESP32 出厂程序 `Config.h`。

| 控制板接口 | 原理图网络 | ESP32 GPIO | 当前用途 | 是否建议给新功能使用 |
| --- | --- | --- | --- | --- |
| J2 扩展口 | `5V/GND/PA5/PA4` | `PA5=GPIO33`，`PA4=GPIO32` | STM32F407 与 ESP32 主通信口 | 不建议给 MaixCAM2 或吸盘占用 |
| J1 扩展口 | `5V/GND/IO13/NC` | `GPIO13` | 普通扩展信号 | 可作为备用单路开关控制 |
| I2C 接口 J5-J8 | `5V/GND/SDA/SCL` | `SDA=GPIO17`，`SCL=GPIO16` | 外接 I2C 模块 | 推荐给 MaixCAM2 传视觉结果 |
| 总线舵机接口 | `BUS_SERVO`，`BUS_EN` 等 | `GPIO12/GPIO35/GPIO14` | 总线舵机通信 | 禁止占用 |
| PWM 舵机口 S1-S6 | `SERVO1` 到 `SERVO6` | `GPIO19/18/5/4/0/15` | PWM 舵机或 PWM 电子开关 | 推荐 S5/S6 控制吸盘 |
| 蓝牙/USB 串口网络 | `TX/RX/TX1/RX1` 等 | 经过复用电路 | 蓝牙、USB、串口控制相关 | 不建议给末端相机长期占用 |

## 3. STM32F407 到 ESP32 接线

此链路保留为 F4 对 ESP32 的高级指令通道。

| STM32F407 | ESP32 控制板 J2 | 说明 |
| --- | --- | --- |
| USART3_TX / PD8 | PA5 / GPIO33 / ESP32 RX | F4 发送命令到 ESP32 |
| USART3_RX / PD9 | PA4 / GPIO32 / ESP32 TX | ESP32 回传状态到 F4 |
| GND | GND | 必须共地 |

当前 ESP32 出厂程序中主串口初始化为：

```cpp
Serial.begin(115200, SERIAL_8N1, PA5, PA4);
```

当前 STM32 工程中 USART3 曾配置为 9600 8N1 用于机械臂协议桥接。后续若 ESP32 侧固定为 115200，则 F4 的 USART3 波特率也必须同步修改；如果继续沿用 9600，则 ESP32 侧也要保持 9600。两端必须一致。

## 4. MaixCAM2 到 ESP32 接线

优先推荐 MaixCAM2 与 ESP32 通过 I2C 通信，原因是 J2 已被 F4 占用，控制板没有额外完整 UART 扩展口。

| MaixCAM2 | ESP32 控制板 I2C 口 | 说明 |
| --- | --- | --- |
| SDA | SDA / GPIO17 | 视觉结果数据线 |
| SCL | SCL / GPIO16 | 视觉结果时钟线 |
| GND | GND | 必须与 ESP32、F4 共地 |
| 5V 或独立供电 | 5V 或独立稳定 5V | 优先使用可靠外部供电，避免机械臂动作时掉电 |

建议 MaixCAM2 不传图像，只传识别结果。推荐数据字段：

| 字段 | 类型建议 | 含义 |
| --- | --- | --- |
| `found` | `uint8_t` | 1 表示找到目标，0 表示未找到 |
| `dx_px` | `int16_t` | 目标相对夹爪抓取中心的 X 像素偏差 |
| `dy_px` | `int16_t` | 目标相对夹爪抓取中心的 Y 像素偏差 |
| `angle_deg` | `int16_t` | 目标角度，单位度 |
| `score` | `uint8_t` | 置信度或匹配分数 |
| `area` | `uint16_t` | 目标面积，用于过滤误识别 |
| `frame_id` | `uint16_t` | 帧序号，用于判断数据是否更新 |

## 5. 吸盘套件接线

推荐购买带 2 个 PWM 电子开关的吸盘套件。这样真空泵和三通电子阀都可以直接通过 PWM 舵机口控制，不需要再飞线额外 GPIO。

| 吸盘部件 | 推荐接口 | 作用 |
| --- | --- | --- |
| 真空泵 PWM 电子开关 | PWM 舵机口 S5 / `SERVO5` | 控制真空泵开关 |
| 三通电子阀 PWM 电子开关 | PWM 舵机口 S6 / `SERVO6` | 控制放气阀开关 |
| 双连杆硅胶吸盘 | 气路连接 | 不占电气引脚 |
| 真空硅胶管 | 气路连接 | 不占电气引脚 |

PWM 电子开关三线定义：

| 线色 | 含义 | 接控制板 |
| --- | --- | --- |
| 黑色 | 电源负极 | 舵机口 GND |
| 红色 | 电源正极 | 舵机口 5V/VBAT |
| 黄色 | PWM 信号 | 舵机口信号脚 |

ESP32 PWM 舵机口与 GPIO 对应关系：

| PWM 舵机口 | ESP32 GPIO | 推荐用途 |
| --- | --- | --- |
| S1 / SERVO1 | GPIO19 | 保留备用 |
| S2 / SERVO2 | GPIO18 | 保留备用 |
| S3 / SERVO3 | GPIO5 | 保留备用 |
| S4 / SERVO4 | GPIO4 | 保留备用 |
| S5 / SERVO5 | GPIO0 | 真空泵电子开关 |
| S6 / SERVO6 | GPIO15 | 三通电子阀电子开关 |

注意：GPIO0 和 GPIO15 是 ESP32 启动相关管脚。控制板原理图已经把它们设计成 PWM 舵机口，正常使用前仍应实测确认：上电、复位、下载程序时 PWM 电子开关不会误触发泵或阀。若出现启动误动作，应改用 S1-S4 中的空闲口。

## 6. 吸盘工作状态

| 阶段 | 真空泵 | 三通电子阀 | 效果 |
| --- | --- | --- | --- |
| 对准目标 | 关闭 | 关闭 | 等待视觉闭环完成 |
| 下降到零件 | 关闭 | 关闭 | 避免提前吸住旁边物体 |
| 吸取 | 开启 300-800 ms | 关闭 | 建立负压，吸住金属零件 |
| 抬起搬运 | 开启或间歇维持 | 关闭 | 保持吸附 |
| 放置 | 关闭 | 开启 200-500 ms | 放气泄压，释放零件 |
| 复位 | 关闭 | 关闭 | 等待下一次抓取 |

## 7. 不建议占用的接口

| 接口 | 不建议原因 |
| --- | --- |
| J2 的 PA5/PA4 | 已经用于 STM32F407 与 ESP32 通信 |
| 总线舵机接口 | 已经用于机械臂总线舵机 |
| 蓝牙/USB 串口网络 | 经过复用和模拟开关，容易影响原有 PC/蓝牙链路 |
| ESP32 的 `GPIO12/GPIO14/GPIO35` | 当前用于总线舵机 TX、方向控制和 RX |
| ESP32 的 `GPIO16/GPIO17` | 推荐保留给 MaixCAM2 I2C |

## 8. 推荐最终接线表

| 功能 | 使用接口 | 占用 ESP32 资源 |
| --- | --- | --- |
| F4 下发抓取命令 | J2 `PA5/PA4` | GPIO33/GPIO32 |
| MaixCAM2 视觉结果 | I2C 口 `SDA/SCL` | GPIO17/GPIO16 |
| 机械臂总线舵机 | 总线舵机接口 | GPIO12/GPIO35/GPIO14 |
| 真空泵 | PWM 舵机口 S5 | GPIO0 |
| 三通电子阀 | PWM 舵机口 S6 | GPIO15 |
| 备用单路开关 | J1 `IO13` | GPIO13 |

## 9. 供电和安全要求

| 项目 | 要求 |
| --- | --- |
| 共地 | STM32F407、ESP32 控制板、MaixCAM2、吸盘电子开关和外部电源必须共地 |
| MaixCAM2 供电 | 建议使用稳定 5V，不要让机械臂动作电流导致视觉模块掉电 |
| 吸盘供电 | 真空泵约 0.35A，电子阀约 0.22A，舵机电源要留出至少 0.6A 以上余量 |
| 感性负载保护 | 若不用成品 PWM 电子开关，泵和阀必须加 MOS 管、续流二极管或驱动模块 |
| 启动误动作 | 程序启动阶段应默认关闭泵和阀，等待 ESP32 初始化完成后再允许动作 |
| 线缆固定 | MaixCAM2 和吸盘安装在末端，线缆必须做应力释放，避免机械臂运动时拉断接口 |

## 10. 后续固件修改建议

| 固件位置 | 修改内容 |
| --- | --- |
| ESP32 `Config.h` | 增加 `VAC_PUMP_SERVO`、`VAC_VALVE_SERVO` 或直接定义 GPIO 映射 |
| ESP32 机械臂服务 | 增加视觉抓取状态机：等待目标、对准、下降、吸取、抬起、放置、释放 |
| ESP32 MaixCAM2 通信模块 | 通过 I2C 读取视觉结果，并缓存最近帧和时间戳 |
| ESP32 协议解析 | 增加 F4 可下发的开始抓取、停止抓取、查询状态命令 |
| STM32F407 | 后续可增加 `ARMGRAB/ARMSTOP/ARMSTATUS` 文本命令，转换为 ESP32 机械臂协议帧 |
